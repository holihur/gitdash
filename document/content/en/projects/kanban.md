title: "Using the board"
weight: 1
summary: "Create projects, configure columns and swimlanes, drag cards, Gantt view."
---

On the repository **Projects** tab:

- Create a project and configure columns (e.g. Todo / Doing / Done) and swimlanes.
- Cards can be issue-linked or free-text notes, and can be dragged between columns.
- Board and Gantt views are available.

See `docs/projects.md` in the repository.
