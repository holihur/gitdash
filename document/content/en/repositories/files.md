---
title: "Browse and edit files"
weight: 5
summary: "Directory browsing, file view, blame, web create/edit/rename, compare."
---

- The **Code** tab browses directories and files by branch, rendering Markdown and Mermaid diagrams.
- **Blame** shows per-line author and commit.
- Create / edit / rename / delete files and folders directly from the web (as commits).
- The **Commits** tab shows a commit graph and search, and supports **Revert** (creates an inverse commit).
- Compare any two branches / tags / commits.
