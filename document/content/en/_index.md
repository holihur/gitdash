gitdash is a minimal self-hosted Git service (think mini-Gitea). It covers repository hosting, issues and pull requests, kanban projects, CI, package registries and an AI copilot. This handbook is organized by **module** and **feature** — useful both for new users getting started and for operators running their own instance.

## Where to start

- New to gitdash: start with [Getting started](getting-started/) — create your first repository in five minutes.
- Manage your account and security: see [Account & security](account/).
- Import existing repositories: see [Repositories · Import](repositories/import/) and [Batch import](repositories/batch-import/).
- Deploy your own instance: see [Self-hosting](self-hosting/).

> Note: this handbook is deployed independently from the application. Point the app at it with `GITDASH_DOCS_URL` and a docs entry appears on the login page and in the header.
