---
title: "Sessions and issue fixes"
weight: 2
summary: "Create a session, chat, and auto-open a PR for a linked issue."
---

Create a session on the repository **Copilot** tab:

- Optionally link an issue; once the agent pushes, gitdash opens a PR automatically (body contains `Closes #N`).
- Ask the agent to inspect or change the repository in the chat.
- You can also trigger it with `gitdash-cli copilot fix <owner/repo> <issue>`.

See `docs/copilot.md` in the repository.
