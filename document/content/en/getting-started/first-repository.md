Click **New repository** in the top-right corner of the home page:

- **Name**: letters, digits, `.`, `_` or `-`, starting with a letter or digit.
- **Description**: optional.
- **Namespace**: your personal space or an organization you belong to.
- **Visibility**: public (everyone) or private (collaborators only).
- **Template**: optionally `readme` to initialize with a README.

After creation you land on the repository page. An empty repository shows the commands for your first push.

## From a template repository

If you mark a repository as **Template**, you can create a new repository from it to bootstrap a predefined file layout.
