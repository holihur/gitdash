title: "SSH keys"
weight: 2
summary: "Add or remove SSH public keys for git clone and push."
---

Add public keys on the **SSH Keys** page:

- Ed25519 / RSA and other OpenSSH public keys are supported.
- A public key can be bound to only one account.
- A public key is your git credential; removing it blocks that machine.

See [Getting started · Set up SSH](../getting-started/connect-ssh/) for generating and testing keys.
