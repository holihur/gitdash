---
title: "批量导入"
weight: 3
summary: "绑定第三方账号后，勾选多个仓库一次导入。"
---

先按 [绑定第三方账号](../account/connected-accounts/) 绑定 GitHub / GitLab / Gitea / Bitbucket。

然后 **Repositories → Import repository → 从已绑定账号导入**：

1. 选择已绑定的平台账号。
2. 加载该账号可访问的仓库列表，可搜索筛选。
3. 勾选一个或多个仓库（支持全选/取消全选），选择是否私有。
4. 点击 **导入**，gitdash 会为每个仓库创建并异步镜像导入。

说明：

- 单个仓库失败不影响其它仓库；结果会提示已排队数量与被跳过的数量（如已存在、URL 非法）。
- 导入使用绑定的 OAuth 令牌访问私有仓库，令牌加密存储、仅用于导入。
- 一次最多导入 100 个仓库。
