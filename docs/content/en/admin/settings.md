---
title: "System settings"
weight: 1
summary: "OAuth/OIDC login, SMTP, feedback, account linking and docs."
---

**Admin → Settings** centralizes:

- GitHub / Google / OIDC login.
- SMTP (email verification, notifications, password reset).
- User feedback target repository and token.
- Third-party account linking (GitLab / Gitea / Bitbucket).
- Documentation site URL (`docs_url`).

Secret fields are write-only: once saved they only show a "set" indicator.
