---
title: "Configure user feedback"
weight: 6
summary: "Enable the floating button and file feedback as issues."
---

Configure under **Admin → User feedback**:

- **Enable feedback**.
- **Issue repository URL**: e.g. `https://github.com/owner/repo` or `https://<host>/owner/repo`. Supports GitHub or Gitea/Forgejo-compatible APIs.
- **Access token**: used to create issues.

When enabled, a floating button appears in the bottom-right corner and submissions create issues in that repository. See [Account · Feedback](../account/feedback/).
