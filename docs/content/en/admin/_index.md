---
title: "Admin panel"
weight: 10
summary: "Admins: settings, login providers, user/repo/org bans, quotas, feedback."
---

Open `http://<host>:8080/admin`. Set `GITDASH_ADMIN_PASSWORD` (and optionally `GITDASH_ADMIN_USER`, default `admin`) before first boot to create the administrator and enable the panel.
