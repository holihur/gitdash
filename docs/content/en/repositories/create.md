See [Getting started · Create your first repository](../getting-started/first-repository/). In addition:

- A repository belongs to a personal or organization namespace.
- Repository settings let you toggle public / private, enable/disable issues, change the default branch and mark it as a template.
- A one-click `git gc` reclaims disk space.
