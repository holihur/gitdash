title: "Install"
weight: 1
summary: "One-line script, Docker and package managers."
---

```bash
curl -fsSL https://raw.githubusercontent.com/holihur/gitdash/main/install.sh | bash
gitdash serve
# Open http://localhost:8080 (SSH :2222)
```

Docker, Homebrew, Scoop, Nix, AUR and apt are also supported. See the repository README.
