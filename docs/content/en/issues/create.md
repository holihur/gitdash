---
title: "Create and edit issues"
weight: 1
summary: "New issue, labels/milestones, pin, state changes."
---

In the repository **Issues → New issue**: add a title and body (Markdown supported), and optionally labels and a milestone. You can:

- Edit / delete.
- Close / reopen.
- Pin to the top (shown first in the list).
- Search by keyword and state.

Issue activity is pushed to watchers.
