---
title: "配置用户反馈"
weight: 6
summary: "开启右下角反馈按钮，把反馈写入指定仓库的 issue。"
---

在 **Admin → 用户反馈** 配置：

- **开启反馈**。
- **Issue 仓库地址**：如 `https://github.com/owner/repo` 或 `https://<host>/owner/repo`。支持 GitHub 或 Gitea/Forgejo 兼容 API。
- **访问令牌**：用于创建 issue 的令牌。

开启后网页右下角出现浮动按钮，用户提交的内容会在对应仓库创建 issue。详见 [账号 · 反馈](../account/feedback/)。
