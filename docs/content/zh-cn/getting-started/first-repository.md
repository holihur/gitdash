在首页右上角点击 **New repository**：

- **Name**：仓库名（字母/数字/`.`/`_`/`-`，字母数字开头）。
- **Description**：可选描述。
- **Namespace**：选择个人或你有权限的组织。
- **Visibility**：public（所有人可见）/ private（仅协作者）。
- **Template**：可选 `readme` 初始化一个带 README 的仓库。

创建完成后进入仓库页面。空仓库会给出首次推送命令。

## 也可以用模板仓库

如果你把某个仓库标记为 **Template**，新建仓库时可以选择「从模板仓库创建」，快速生成一个预置文件结构的新仓库。
